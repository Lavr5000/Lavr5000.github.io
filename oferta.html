03 Акцепт оферты

Акцептом настоящей оферты (ст. 438 ГК РФ) является совершение Клиентом любого из следующих действий:

  1. направление заявки Исполнителю (в Telegram или по email);
  2. передача файлов для обработки любым согласованным способом;
  3. оплата счёта или чека Исполнителя.

Для услуг направления Б (настройка программного обеспечения) акцептом является совершение Клиентом любого из следующих действий:

  1. оплата счёта или платёжной ссылки Исполнителя на выбранную единицу услуги;
  2. письменное подтверждение Клиентом состава услуги и её стоимости в переписке (Telegram или email) в ответ на предложение Исполнителя.

Передача файлов акцептом услуг направления Б не является: при настройке файлы Исполнителю не передаются.

С момента акцепта настоящая оферта приобретает силу двустороннего договора на условиях, изложенных ниже.

Создание личного кабинета (регистрация) не является обязательным условием акцепта настоящей оферты и оформления заказа: Клиент может оформить заказ и оплатить услугу анонимно, без регистрации, указав адрес электронной почты для получения результата и кассового чека. Регистрация личного кабинета — самостоятельное добровольное действие Клиента, доступное дополнительно к оформлению заказа, в том числе после получения результата.

Клиент гарантирует, что передаваемые файлы:

  • принадлежат ему на праве собственности, либо переданы ему правообладателем с разрешением на привлечение третьих лиц для обработки;
  • не содержат сведений, составляющих государственную, служебную или коммерческую тайну, или Клиент имеет законные основания раскрывать такие сведения Исполнителю;

Отказ в обработке. Если Исполнитель обнаружит, что файлы содержат грифы «Секретно», «ДСП», «Конфиденциально» или иные признаки документов с ограниченным доступом, либо содержат явные персональные данные третьих лиц, не связанные с предметом услуги, Исполнитель вправе отказать в обработке и уведомить Клиента. В этом случае уже полученная оплата возвращается в полном объёме.

Ответственность за несоответствие гарантий, данных Клиентом в настоящем разделе, действительности лежит исключительно на Клиенте.

06 Хранение файлов и retention-политика

Срок хранения исходных файлов Клиента — 14 календарных дней с момента передачи результата. По истечении этого срока исходные файлы удаляются автоматически.

Продление срока хранения сверх 14 дней возможно только при наличии явно выраженного согласия Клиента (opt-in), отмечаемого при оформлении заказа. При наличии такого согласия исходный файл, по которому Клиент оставил оценку «есть замечания» с причиной о качестве извлечения данных, хранится до 90 календарных дней для разбора спорного случая, после чего удаляется. При отсутствии согласия хранение сверх 14 дней не производится. Согласие может быть отозвано в любой момент (Telegram @lavr5000 или email); после отзыва данные удаляются в срок не более 10 рабочих дней.

После выполнения заказа Клиенту в письме с результатом может быть предложено добровольно оценить результат (оценка «подошла» / «есть замечания», причина, необязательный комментарий). Оценка не обязательна, не влияет на получение результата и используется только для контроля и улучшения качества обработки. Ссылка для оценки действительна 30 дней.

Производные артефакты (результирующие таблицы, тест-кейсы, внутренние контрольные данные) сохраняются только в виде агрегатов, прошедших процедуру деанонимизации: шифры объектов, наименования организаций, адреса и ФИО из исходных файлов вычищаются до архивирования любых внутренних данных.

Исполнитель не несёт ответственности за потерю файлов на инфраструктуре сторонних платформ (Telegram и иных), используемых Клиентом для передачи.

Личный кабинет и хранение файлов. Наличие зарегистрированного личного кабинета не изменяет и не продлевает сроки хранения исходных файлов, установленные настоящим разделом: файлы удаляются по общим правилам независимо от того, оформлен заказ анонимно или из личного кабинета. В личном кабинете сохраняется только история заказов в виде метаданных (дата, вид услуги, статус) — без самих файлов и без их содержимого.

07 Обработка данных и конфиденциальность

Режим обработки по умолчанию — локальный, детерминированный. Обработка исходных файлов Клиента выполняется локально, без передачи сырых данных в облачные AI-сервисы.

Использование облачных AI-сервисов допускается только в одном из двух случаев:

  1. на обезличенных фрагментах документации, прошедших предварительную вычистку (шифры, наименования объектов и организаций, ФИО, адреса удалены); либо
  2. при наличии явного письменного согласия Клиента на передачу конкретных фрагментов в облачный сервис с указанием поставщика. Возможные поставщики облачных AI-сервисов: Anthropic (Claude), OpenAI (GPT), Google (Gemini); конкретный поставщик называется Клиенту в момент запроса согласия.

Сырые файлы Клиента никогда не передаются в облачные AI-сервисы без соответствующего согласия.

Обработка сервиса «Печатные накладные М-15 → Excel». Для распознавания отсканированных печатных накладных загруженный PDF преобразуется в изображения страниц, которые вместе с извлекаемыми данными передаются внешнему сервису распознавания (OpenRouter) — только для формирования Excel-результата. Исходный файл и распознанные данные удаляются после доставки результата на указанный email. При неуспешной обработке файл хранится не более 7 дней (для разбора качества) и затем удаляется; расширенное хранение для данного сервиса не применяется. Сервис рассчитан на печатные формы М-15; рукописные накладные принимаются только как best-effort без гарантии качества распознавания. Заказчик подтверждает наличие права на передачу загружаемого документа.

Персональные данные, полученные от Клиента в ходе оказания услуг, обрабатываются в соответствии с Политикой конфиденциальности.

08 Telegram как канал передачи файлов

Заявки и файлы принимаются в том числе через Telegram (@lavr5000). Клиент понимает и принимает следующее:

10 Статусы уверенности в результатах

Каждый результат обработки может содержать статус уверенности, характеризующий качество и способ извлечения данных. Полная легенда статусов предоставляется вместе с результатом. Основные статусы:

  • OK — данные извлечены детерминированно из векторного слоя, высокая надёжность;
  • PIVOT — данные извлечены с применением дополнительного метода; рекомендуется проверка;
  • VECTOR — данные получены из структурированного векторного слоя PDF;
  • MANUAL_GEOMETRY — значение определено геометрически или вручную; требует проверки;

Клиент обязуется учитывать статусы при использовании результатов.
