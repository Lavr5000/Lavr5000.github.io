# lavr5000.github.io

Single-file portfolio-landing of Denis Lavrov (construction automation + AI).

## Structure

```
index.html           — main page: the two AI setup services (assets/site2.css + assets/index2.app.js)
services/index.html  — services page, same design system, stable URL for posts
assets/hero-demo.js  — frames of the hero terminal, generated by scripts/build_hero_demo.py
robot.glb            — 3D robot model (model-viewer, about.html)
uploads/             — static images / screenshots
apartment-auditor/   — privacy policy for the Apartment Auditor RuStore app
favicon*.png         — favicons
.github/workflows/deploy-pages.yml — deploys repo root as-is to GitHub Pages
```

## Local preview

python -m http.server 8765 --bind 127.0.0.1
